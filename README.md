# Expense Tracker

## Description
A simple Python Expense Tracker that records daily expenses with date, category, and amount.

## Features
- Records multiple expenses.
- Stores expense records as dictionaries.
- Validates dates and amounts.
- Calculates total spending by category.
- Exports expenses to a CSV file.

## Requirements
- Python 3
- No external libraries required.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run `main.py`.
4. Enter your expense details.
5. The program creates an `expenses.csv` file.

## Technologies Used
- Python
- CSV module
- Datetime module
